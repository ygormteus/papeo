## Correções

- **Atualização no Mac:** se o Mac estiver abrindo o Papeo de uma cópia temporária (acontece quando o app ainda está marcado como baixado da internet), a atualização falhava com "Read-only file system". Agora o Papeo avisa e mostra o que fazer: fechar o app e rodar no Terminal `xattr -dr com.apple.quarantine /Applications/Papeo.app`. Se estiver aberto direto do instalador, pede para arrastá-lo para a pasta Aplicativos.
