## New

- **Redesigned Home**: alerts at the top when an account signs out, freezes or gets heavy, with a button to fix it right there.
- **Recent chats on Home**: read and reply to the latest messages without switching accounts.
- **Summary in the top bar**, next to search: services, unread, memory and downloads. Each item is a shortcut (open the account with the most unread, free up memory, open the downloads folder).

## Improvements

- The services table now adapts to narrow windows without cutting off buttons.
- More usable space on Home: the numbers moved from the cards to the top bar.
