## New

- **More reliable quick reply when the site changes:** Papeo now notices when WhatsApp or Telegram change the page and it can no longer find the text field, the search or the chat name. In that case, the "Reply" button disappears for that account (in the notification and the mini window) until the site is back to normal, instead of trying and failing.
- **Site diagnostics:** in **Settings → System → Site diagnostics**, see what Papeo finds in each open account and copy a report to describe a problem (without account or chat names). With **diagnostic mode** on, a "Site changed" alert appears at the top when something goes missing.

## Improvements

- **Smoother with many accounts:** memory measurement, downloads, backup and task sync no longer freeze the window for moments while they work on disk.
